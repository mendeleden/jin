# Desktop CSP Requires Class-Based Renderer Visuals

## Problem

The Electron renderer runs under a strict Content Security Policy. CDP smoke
testing showed that chart bars and tree indentation rendered with inline
`style` attributes triggered `style-src 'self'` violations. Data loaded
correctly, but visual elements could silently disappear or degrade.

## Solution

Replace renderer-generated inline styles with bounded CSS classes. Dynamic
token chart colors use `usage-color-*`, chart widths use bucketed
`usage-share-*`, and tree indentation uses capped `tree-depth-*` classes.

## Key Insight

Desktop renderer HTML is still untrusted surface area, even when generated by
our own TypeScript. Any visual that needs dynamic sizing or color should map
data into an explicit class allowlist instead of emitting inline style text.

## Prevention

Include CDP smoke checks for zero inline `style` nodes and zero inline-style
CSP violations when validating Desktop renderer changes that add charts,
graphs, trees, or other data-driven visuals.
