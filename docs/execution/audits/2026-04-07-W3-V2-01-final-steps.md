### 2. Rebuild/install current binary

1. Run `bun run build`.
2. Install the fresh `./jin` on the path that the operator and any service
   wrapper will actually use. Current service/binary discovery in
   `src/commands/service.ts` checks `~/.local/bin/jin`, `~/.bun/bin/jin`, and
   `/usr/local/bin/jin`.
3. Smoke the installed binary from that path with:
   - `jin version`
   - `jin help team`
   - `jin status --json`
4. If preview testing includes service mode, verify the generated
   `jin service install` unit or scheduler entry points at the rebuilt binary
   before using `jin start --service`.

### 3. Local Docker/Postgres E2E

1. Start local Postgres with
   `docker compose -f test/docker-compose.integration.yml up -d --wait postgres`.
2. Treat `bun run test:integration` as optional generic sink plumbing preflight
   only. It validates Postgres/S3/MinIO wiring, not the operator/developer
   persona flow from `W3-E2E-01`.
3. Operator bootstrap with the current binary:
   - `jin team schema apply --connection-string="postgresql://jin_test:jin_test@localhost:5444/jin_test"`
   - `jin team bridge --type=postgres --connection-string="postgresql://jin_test:jin_test@localhost:5444/jin_test" --name=team-local`
   - capture the emitted `jin connect --team=<code>`
4. Developer onboarding:
   - developer A runs `jin connect --team=<code>`
   - developer B runs `jin connect --team=<code>`
5. Runtime smoke with the same binary:
   - `jin start --foreground` for visible runtime/store behavior
   - or `jin start` followed by `jin status` if the detached daemon path is the
     explicit thing under test for this pass
6. Verify `jin status --json` reports the runtime state, store path,
   non-zero sessions/messages after ingest, and the configured sink.
7. Record any manual read-surface verification needed by `W3-E2E-01`, then tear
   down with `docker compose -f test/docker-compose.integration.yml down -v`.

   - the local Docker/Postgres persona flow ran end to end with that binary

3. `No-go` if runtime approval slips, the installed binary smoke diverges from
