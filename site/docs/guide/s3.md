# S3 / R2 Sink

Push session data to S3-compatible storage (AWS S3, Cloudflare R2, MinIO, GCS).

## Setup

```sh
jin team-config \
  --type=s3 \
  --bucket=jin-sessions \
  --region=us-east-1 \
  --access-key-id=AKIA... \
  --secret-access-key=... \
  --team-id=my-team
```

## Cloudflare R2

```sh
jin team-config \
  --type=s3 \
  --bucket=jin-sessions \
  --endpoint=https://ACCOUNT.r2.cloudflarestorage.com \
  --access-key-id=... \
  --secret-access-key=... \
  --team-id=my-team
```

## File structure

Sessions are stored as JSON files:

```
jin-sessions/
  my-team/
    developer-a/
      claude-code/
        abc-123.json
      codex/
        def-456.json
    developer-b/
      ...
```
