## Verify the binary

```sh
jin --version
jin status
```

## Build from source

Requires [Bun](https://bun.sh).

```sh
git clone https://github.com/mendeleden/jin.git
cd jin
bun install
bun run build
mv jin ~/.local/bin/
```

## Next step

Run `jin init` to detect your local AI coding tools and create the initial config.
