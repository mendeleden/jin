Use object storage for archival, data lake ingestion, and compliance exports.

## S3-compatible setup

```sh
jin team-config \
  --type=s3 \
  --bucket=jin-sessions \
  --region=us-east-1 \
  --access-key-id=AKIA... \
  --secret-access-key=... \
  --team-id=platform
```

## Cloudflare R2

```sh
jin team-config \
  --type=s3 \
  --bucket=jin-sessions \
  --endpoint=https://ACCOUNT.r2.cloudflarestorage.com \
  --access-key-id=... \
  --secret-access-key=... \
  --team-id=platform
```

Objects are written as normalized session batches for downstream analysis.
