jin

Capture every AI coding session. Index across all your tools. One daemon watches everything.

$ curl -fsSL https://builtbyeden.app/install.sh | sh

macOS & Linux · single binary · zero config

01 — Capabilities

Everything your AI conversations produce, captured

10 adapters

Every tool, one pipeline

Claude Code, Cursor, Codex, Warp, Gemini CLI, Kiro, Amp, OpenCode, Pi, PiAgent — all indexed into a single store.

3 sinks

Push anywhere

Webhook, PostgreSQL, or S3. Stream sessions to your team's infrastructure in real-time.

auto-tag

Smart grouping

Sessions auto-tagged by project, tool, model family, language, and cost. No manual labeling.

artifacts

Context captured

Memory files, rules, configs, plans, todos — the full context around every session, indexed.

daemon

Always running

Background daemon or OS service. Survives reboots. Watches for changes and ingests automatically.

self-update

Stays current

Checks for updates on startup. One command to upgrade in place. No package manager needed.

02 — Setup

Three commands. That's it.

01
$ jin init

Detects which coding tools you have installed. Creates config. Connects to team sinks if you have a team code.

02
$ jin watch --daemon

Starts background monitoring. Watches all detected tools for new sessions. Ingests and pushes to sinks automatically.

03
$ jin analyze

Token usage, cost breakdown by tool and project. See which models and tools your team is actually using.
